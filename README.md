# ChatApp

Site internet de messagerie instantanée.

## Description

**ChatApp** est une application web de messagerie instantanée. Elle propose une page d'accueil, une page de chat et une page d'aide.

## Fonctionnalités

- Envoi et réception de messages en temps reel
